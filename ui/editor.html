Measurement Definitions

Length and width: moment-equivalent ellipse axes. Aspect ratio = Length / Width. Equivalent diameter = 2√(Area/π). Roundness = 4Area/(πLength²), a 2D shape measure.

Statistics use the filtered pore list. Std: sample standard deviation (n−1). † Boundary pore: visible area only. Undefined values are omitted.
